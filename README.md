# プログラマのための機械学習、AIシステムへのいざない

　本コンテンツは一般のITエンジニア、プログラマを対象にAI,機械学習の基礎的な事柄について説明するものである。  
説明にあたり実際に動くプログラムを多用はしているが、基本的な考え、理論をコード化したもので実用ベースな記述とは異なる。  
基本原理を理解したい人には向いているが、実務に即役立つという内容ではない。  
　機械学習には数学的な要素も重要であるが、その究明を目的としたものではない。他、用語や応用例も多く、多岐、多様にわたっているので基本的な事柄についてのみ説明し、その応用、それぞれの実務にあわせた適用についてはネットやAIとの問答も利用して理解を深められたい。
 　作者はITシステムの経験は長いが、AIシステムの開発経験、ノウハウはほとんどない。システム***QAR***（QARへのリンク）の改善を考え、AIの取り込みを模索し学習した。その忘備もかねニューラルネットワークまでを大きな区切りとして作成したものである。今後も拡充するつもりではいるが、今のところ「AIシステムへのいざない」には、まだ、なかなか遠い内容である。
 
 　コード例はPythonを基本としているが、WEB上で動作して見せることもありJavaScriptの場合も多い。Pythonの場合はGoogle Colabでの実行を考慮して提供している。

 [１．機械学習の基本](1.MachineLearningBasic)  
　　基本的、な機械学習の方法についてコードを用いて具体的に説明している。

[２．学習プロセスの構成について](2.Configuration)  
　　１．で使用した式、パラメータの意味、バリエーションを説明し機械学習に関する知識の幅を広める。選択によりどのような効果、作用があるかのデモプログラムで体感する。

[３．16x16での図形認識](3.16x16Dots)  
　　応用的な素材として16x16のドットパターンの学習をコード化して、その効果を見せている。

[４．ベクトル・行列](4.VectorMatrix)  
　　３．の内容を３つのパターンへと機能拡張している。また素の言語機能での実装とNumpy, Torchなど、機械学習上必須となってくるライブラリを使用したコードでの実装の二つをおこないベクトル・行列化の例を説明している。

[５．文字、Token処理](5.Text)  
　機械学習を文字、文章へと発展させる足がかりとして文字、トークン認識についてコードを用いて説明。実用には程遠いことを実感するものである。

[６．次元削減](6.DimensionalityReduction)
