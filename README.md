# プログラマのための機械学習、AIシステムへのいざない

本コンテンツは一般のITエンジニア、プログラマを対象にAI,機械学習の基礎的な事柄について説明するものである。  
説明にあたり実際に動くプログラムを多用はしていますが、基本的な考え、理論をコード化したもので実用ベースな記述とは異なる。  
基本原理を理解したい人には向いているが、実務に即役立つというノウハウではない。  
機械学習には数学的な要素も重要であるが、それには深くふれず、使われる数式の内容や応用、その他例、設計上の留意事項について説明している。  
用語の意味や数学的根拠については深く説明しないので、疑問をもった点についてはネットやAIを活用して調べられたい。  
今後も充実していく予定ではあるが、今のところAIへのいなざいにはなかなかなっていない。  
作者はITシステムの経験は長いが、AIのノウハウはほとんどなく、システムQARの改善を考え、AIの取り込みを模索し学習した結果である。（QARへのリンク）
