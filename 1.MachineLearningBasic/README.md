# 第1章 機械学習の基本 ― y = a*x + b から始める
## 1. はじめに

機械学習というと、ニューラルネットワーク、生成AI、LLMなど複雑な仕組みを思い浮かべるかもしれない。
しかし、ここでは機械学習の基本、簡単な式から説明をおこなっている。
まず、中学の数学で習う一次式 y = a * x + b それについて機械学習を実践してみる。
またプログラミングというとPyhtonでPyTorchとなるようだが、ここでは素の言語の機能での実装を今はおこなっており、サンプルとしてはデモで動かす都合上、JavaScriptを用いている。

## 2.サンプル
学習データ
| x | y |
| ---: | ---: |
| 1 | 3 |
| 2 | 5 |
| 4 | 9 |
| 5 | 11 |

とした場合、x=7の場合yの値を考える。
AIにかけるまでもないと思うものであるが、ここではプログラム、機械がどのようにして学習していくかを過程を説明するものである。
a、b に初期値を設定し、予測値と正解値の誤差をもとに値を繰り返し補正することで、データ群に合致した a、b 	を求める。  

設定条件表
| 番号 | 項目 | 設定・内容 |
| :---: | :---: | :--- |
| ① | モデル | `y = a*x + b` |
| ② | パラメータ | `a, b` |
| ③ | 初期値 | `a=0, b=0` |
| ④ | 損失関数 | `(予測値 - 正解値)**2` |
| ⑤ | 勾配 | 損失関数を a,b について微分して求める |
| ⑥ | 学習率 | `0.01` |
| ⑦ | epoch（回数） | `100` |

・学習率は、計算した勾配（gradient）をもとに、パラメータを一度の学習でどの程度変化させるかを決める係数である。
・損失関数は、予測値と正解値の違いをどのような数値として評価するかを決める式である。
・モデルには、このデータでは直線的な関係があると予測し、y = a*x + b をモデルとして使用している。
・正には、損失関数を微分した値（傾き）が用いる。

[1次元学習デモ](https://tasamu61.github.io/MyAiStudyPre/1.MachineLearningBasic/01-1OneDimension.html)
学習回数は、1回でも累積実行できるので、学習の効果を実感されたい。

> 💡 **補足：勾配の具体的な計算例**
> 
> ここで勾配とは、Lossを小さくするためにパラメータをどちらに動かせばよいかを示す値である。
> 
> 例えば学習途中で `a=2`、`b=2` とすると。学習データ `x=3`、正解値 `y=7` の場合、予測値は
> `2 * 3 + 2 = 8`
> となるため、誤差は `8 - 7 = 1` である。
> 
> 誤差を次の損失関数で表す。
> $$\text{Loss} = (a \cdot x + b - y)^2$$
> 
> このLossを、学習によって変化させるパラメータ $a$ と $b$ についてそれぞれ偏微分すると、次のようになる。
> 
> * **aについて：** $\frac{\partial \text{Loss}}{\partial a} = 2(a \cdot x + b - y) \cdot x \implies 2 \times \text{誤差} \times x = 6$
> * **bについて：** $\frac{\partial \text{Loss}}{\partial b} = 2(a \cdot x + b - y) \implies 2 \times \text{誤差} = 2$
> 
> この値がそれぞれのパラメータに対する勾配である。この勾配に学習率を掛け、 $a$ と $b$ を補正する。

> 🔗 **実際に触って確かめる**
>
> 上の計算をパラメータ a ひとつだけに単純化し、実際に手を動かして確認できるデモを用意した。
> 「①学習データと今の直線」「②予測値と正解のズレ（誤差）のクローズアップ」「③Loss(a)の谷とボールの位置」の3つを見比べながら、
> 勾配がどこから求まり、どちら向きにパラメータを動かせばLossが下がるのかを体感できる。
>
> [勾配ってなに？— パラメータ1つだけで見る](https://tasamu61.github.io/MyAiStudyPre/1.MachineLearningBasic/01-2func.html)

## 3.コード例
実際にブラウザ上で動作するデモプログラムの機械学習を抜粋したのが以下のコードである。２．の設定条件表の内容と重ねあわせて内容を確認されたい。  

```JavaScript
// 学習データ
const data = [
    [1, 3],
    [2, 5],
    [4, 9],
    [5, 11]
];

// ②③初期値
let a = 0;
let b = 0;

// ⓺学習率
const learningRate = 0.01;

// 機械学習を実装したロジックであり、
// ここれは回数を⑦count可変としている。
function train(count) {

	// 指定数、学習を繰り返す
    for (let n = 0; n < count; n++) {
        let gradA = 0;
        let gradB = 0;
        
        let loss = 0;

        // 指定数繰り返す
        for (const [x, y] of data) {
            // ①モデル式で計算して
            const prediction = a * x + b;
            // ④誤差を求める
            const diff = prediction - y;
            // 損失関数として二乗し損失を求める。
            loss += diff * diff;

            // ⑤a,bについて微分した値、勾配を求める。
            gradA += 2 * diff * x;
            gradB += 2 * diff;
        }
        Tloss = loss;
        // データ数で割り１件あたりに
        gradA /= data.length;
        gradB /= data.length;

        a -= learningRate * gradA;
        b -= learningRate * gradB;

    }

    draw(); // 結果表示
}
```
