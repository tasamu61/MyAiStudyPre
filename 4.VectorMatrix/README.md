# 4．ベクトル・行列

第3章では、16×16のドットで構成された1種類のパターン認識を扱った。本章ではこれを拡張し、`|`、`-`、`/` の3種類を判定する。

各種類について5件ずつ、合計15件の学習データを使用する。学習の基本はこれまでと同じで、**予測 → Loss → 勾配 → パラメータ更新**を繰り返す。

一方、扱うデータは大きくなる。16×16の図形1件は256個の数値で表され、15件なら `15×256` 個になる。このような多数の数値をまとめて扱うために、機械学習ではベクトル・行列が多く使われる。

[16×16 3パターン認識デモを実行](https://tasamu61.github.io/MyAiStudyPre/4.VectorMatrix/04-3VectorMatrixDemo.html)

## 4-1．3種類のパターンを判定する

クラス番号を次のようにする。

| クラス | パターン | 学習データ |
|---:|:---:|---:|
| 0 | `|` | 5件 |
| 1 | `-` | 5件 |
| 2 | `/` | 5件 |

実際の学習データの一例を表示すると次のようになる。

**`|`（0_01.txt）**
```text
                
                
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
       ■        
                
                
```

**`-`（1_01.txt）**
```text
                
                
                
                
                
                
                
  ■■■■■■■■■■■■  
                
                
                
                
                
                
                
                
```

**`/`（2_01.txt）**
```text
                
                
             ■  
            ■   
           ■    
          ■     
         ■      
        ■       
       ■        
      ■         
     ■          
    ■           
   ■            
  ■             
                
                
```

16×16の1件のデータは、左上から順に並べて256個の数値にする。

```text
16 × 16 = 256入力
```

3種類を判定するため、それぞれのクラスに256個の重みを持つ。

```text
重み    : 3 × 256 = 768個
バイアス: 3個
パラメータ数 = 771個
```

第3章より規模は大きくなったが、学習によってパラメータを調整するという基本的な考え方は同じである。

## 4-2．まずPythonの配列だけで処理する

[04-1Primitive.ipynb](04-1Primitive.ipynb) はGoogle Colabで実行できるNotebookである。外部ファイルをアップロードしなくても試せるよう、15件の学習データをNotebook内に持たせている。

予測値は概念的には次の処理を3クラス分行う。

```python
value = bias[cls]
for i in range(256):
    value += bits[i] * weights[cls][i]
```

つまり、256個の入力と256個の重みを掛け、その合計にバイアスを加えている。

## 4-3．同じデータを行列として見る

15件の学習データをまとめると、入力 `X` は次の形になる。

```text
X : 15 × 256
```

3クラス分の重みは、

```text
weights : 3 × 256
```

である。予測では `weights` を転置して、

```text
(15 × 256) @ (256 × 3) → (15 × 3)
```

と計算する。

結果の `15×3` は、**15件それぞれについて3種類の判定値が得られたもの**である。

```python
prediction = X @ weights.T + bias
```

Python版で `for` 文を使って1個ずつ行っていた掛け算と加算を、行列演算ではこの1行でまとめて表現できる。

## 4-4．NumPyで行列として処理する

[04-2NumPy.ipynb](04-2NumPy.ipynb) もGoogle Colabでそのまま実行できる。

```python
X = np.array([td["bits"] for td in training_data])

weights = np.zeros((3, 256))
bias = np.zeros(3)

prediction = X @ weights.T + bias
```

Lossから求めた勾配についても、15件をまとめて計算できる。

```python
gradient = 2 * diff
weight_gradient = gradient.T @ X
bias_gradient = np.sum(gradient, axis=0)

weights -= rate * weight_gradient
bias -= rate * bias_gradient
```

処理内容そのものが別物になったわけではない。**多数の同じ種類の計算を、ベクトル・行列としてまとめて記述している**。

## 4-5．なぜ機械学習でベクトル・行列を使うのか

画像、音声、文章などをコンピュータで扱うと、多数の数値を処理することになる。1個ずつ変数を用意して計算するより、ベクトルや行列としてまとめた方が、モデルの構造を簡潔に表現できる。

またNumPyやPyTorchなどは、このような行列計算を効率よく処理する機能を持っている。後に扱うニューラルネットワークでも、大量の入力とパラメータの計算は行列演算として行われる。

ここでは行列そのものの数学を詳しく扱うことを目的とはしない。まず、

```text
15件 × 256入力
        ↓
行列としてまとめて計算
        ↓
15件 × 3出力
```

というデータの形と処理の対応を理解されたい。
