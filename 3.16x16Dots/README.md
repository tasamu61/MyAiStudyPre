# ３．16x16での図形認識

1．と2．では、数式として分かりやすい線形要素を扱ったが、今度は16×16のドットで構成される文字パターン認識を扱う。

一次式 y = a*x + b では、学習するパラメータは a, b の2個、y = a*x1**2 + b*x2 + c なら a, b, c の3個である。
今度は16×16個の入力それぞれに重みを持たせるため、256個の重み＋バイアス1個で、257個のパラメータを学習する。

LLMではモデルの規模を7B、13Bなどと表現することがある。このBはbillion（10億）を表し、7Bなら約70億個のパラメータという意味である。

学習によってパラメータを調整する、という基本的な考え方は同じであるが、今回はパラメータの数、モデルの形が大きく異なる。多様なモデルのあり方の一例として、本章では16×16の文字パターン認識を扱う。

これは特定位置の256個のドットがオンか否かだけでは判断するものであり、隣接する要素との関連、１列右、１段上に移動するなど、図形独自の概念を考慮するロジックは一切含まれていない。
複数の学習データにより小さいが一定の判断基準をもつことがわる。
