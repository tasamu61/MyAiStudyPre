# ３．16×16での図形認識

1．と2．では、数式として分かりやすい線形要素を扱ったが、今度は16×16のドットで構成される文字パターン認識を扱う。

一次式 y = a*x + b では、学習するパラメータは a, b の2個、y = a*x1**2 + b*x2 + c なら a, b, c の3個である。
今度は16×16個の入力それぞれに重みを持たせるため、256個の重み＋バイアス1個で、257個のパラメータを学習する。

LLMではモデルの規模を7B、13Bなどと表現することがある。このBはbillion（10億）を表し、7Bなら約70億個のパラメータという意味である。

学習によってパラメータを調整する、という基本的な考え方は同じであるが、今回はパラメータの数、モデルの形が大きく異なる。多様なモデルのあり方の一例として、本章では16×16の文字パターン認識を扱う。

これは特定位置の256個のドットがオンか否かだけでは判断するものであり、隣接する要素との関連、１列右、１段上に移動するなど、図形独自の特性を考慮するロジックは一切含まれていない。
複数の学習データにより効果は小さいが一定の判断基準をもつことがわかる。

## 3.3 1 サンプルデータ

16×16マスの中に「■」を置くかどうかだけで図形を表す。例えば、教師データの一部はこのような形である。

```
「1」（教師データ 1_01.txt）      「1ではない」（教師データ 0_04.txt）
       ■                              ■
      ■■                              ■
       ■                              ■
       ■                              ■
       ■                        ■■■■■■■■■
       ■                              ■
       ■                              ■
       ■                              ■
       ■
       ■
       ■
       ■
      ■■■
```

ファイル名の先頭が`1_`なら「1である」、`0_`なら「1ではない」という教師ラベルを表す。今回は
「1」らしい縦棒の図形を10件（1が5件、1でないものが5件）だけ用意した、ごく小さなデータセットである。

これらのファイルを実際にひとつずつ読み込んで学習する、オリジナルのPythonプログラムは

## 3.3 2 データと判定方式、モデルの説明

- **入力**：16×16=256マスそれぞれのON(1)/OFF(0)
- **モデル**：256個の重み（各マスに1つずつ）＋バイアス1個。あわせて257個のパラメータ
- **予測式**：z = w1\*x1 + w2\*x2 + ... + w256\*x256 + b を求め、シグモイド関数 σ(z) = 1 / (1 + e\*\*-z) に通して0〜1の値にする
- **判定**：予測値が0.5以上なら「1である」、未満なら「1ではない」

1章のy=a\*x+bと発想は同じで、「入力に重みを掛けて足し合わせ、正解に近づくよう重みを補正する」という
学習の仕組みそのものは変わらない。違うのはパラメータの数（2個→257個）と、値を0〜1に収めるための
シグモイド関数が加わった点である。

## 3.3 3 サンプルプログラム（Python）

以下の①〜⑤の手順で学習する。1・2章から一貫して使っている手順（予測→Loss→微分→補正）と同じである。

- ①予測：現在の重み・バイアスで予測値を出す（z = w1\*x1 + ... + b を求めてから p = σ(z) にする）
- ②Loss：Loss = (p-t)\*\*2（予測値と正解の差の2乗）
- ③微分：欲しいのは ∂Loss/∂z （zを動かすとLossがどう変わるか）。
  pを介した連鎖律（chain rule）で、2段階に分けて求める。

  まず、Lossをpで微分すると

  ```
  ∂Loss/∂p = 2*(p-t)
  ```

  次に、p = σ(z) をzで微分すると（シグモイド関数自身の微分）

  ```
  ∂p/∂z = p*(1-p)
  ```

  この2つを連鎖律で掛け合わせると

  ```
  ∂Loss/∂z = ∂Loss/∂p * ∂p/∂z = 2*(p-t) * p*(1-p)
  ```

  1章のLoss=(p-t)\*\*2の微分と同じ2\*(p-t)に、シグモイド関数自身の微分p\*(1-p)が
  掛け算で加わった形になっている。
- ④256個のweightを補正：ONになっているマスの重みだけを、勾配ぶん補正する
- ⑤biasを補正
