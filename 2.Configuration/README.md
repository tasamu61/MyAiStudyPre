# ２．学習プロセスの構成
　１．ではデモプログラムを提示し、実行したがそれを構成する内容について機械学習上で持つ意味、効果などについて説明する。
その詳細やシステム化における現場での応用実例については、本章での説明をもとにしてAIなどを活用し、理解を進めていただきたい。


式、モデル	y=a*x+c を使用したが、	
	二次式：y=a*x²+b*x+c	
	三次式：y=a*x³+b*x²+c*x+d	
	や他にも多くの数式が考えられる。
	実際のデータ、目的などによって決まるか、あるいはいくつか試行することが必要かもしれない。
	非常に多様な事柄であり、ここではいくつかの例の説明にとどめる。より詳しくは以下のようなフレーズでAIに問いかけて、納得いくまで問答を続けるこをと勧める。
	「二次式による回帰が実際の業務で使われる例を、ITエンジニア向けに教えて」	
	「一次式では表現できず、二次式なら表現できる現実のデータの例は？」	
	「三次式による回帰を使う実務上の例は？」	
	「一次、二次、三次のモデルから、実際の機械学習ではどうやってモデルを選ぶ？」	
	「モデルを複雑にしすぎると、なぜ過学習が起きる？」	
		
損失関数	(予測値 - 正解値)**2	
	予測値と正解値がどの程度違っているかを数値で表すための関数である。	
	今回採用した二乗誤差（Squared Error） で、回帰では非常に一般的、複数データなら、	
	その平均を取った MSE（平均二乗誤差） がよく使われる。
	いくつかの方法があるが、損失関数をキーワードにすれば多くの情報が得られる。	

初期値	a=0, b=0	
	学習を始める前に、パラメータ a, b にどんな値を入れておくかという設定である。
	今回のように「一次式＋二乗誤差」の組み合わせは、グラフにするとお椀を伏せたような形（凸関数）になっており、
	どこから転がし始めても、最後は同じ底（最適解）にたどり着く。そのため初期値を 0 にしても問題は起きない。
	ただし式が複雑になったり、後述のように損失関数の形が単純な谷ではなくなったりすると、
	初期値によって「どの谷に落ち着くか」が変わってしまうことがある（局所解）。
	この点は、下記「谷がひとつじゃない場合」で実際に確認できる。

学習率	0.01	
	１回の学習で、勾配（傾き）をもとにパラメータをどれだけ動かすかを決める係数である。
	大きすぎると値が行き過ぎて発散し、Lossがどんどん大きくなってしまう。
	小さすぎると一歩の動きが小さすぎて、なかなか最適解にたどり着かない。
	また式の次数が上がる（二次、三次になる）ほど勾配自体の値が大きくなりやすいため、
	同じ学習率でも次数が高い式では発散しやすくなる。次数に応じて学習率の目安を小さくする必要がある。

epoch（回数）	100	
	学習（パラメータの補正）を何回繰り返すかという設定である。
	回数を増やせば増やすほどLossが下がり続けるわけではなく、ある程度で下げ止まる。
	下げ止まった後にepochだけ増やしても、結果はほとんど変わらない。
	何回で下げ止まるかは、データのばらつきや学習率、式の次数によって変わってくる。

## 3.サンプルプログラム
　１．の設定条件表（モデル・パラメータ・初期値・損失関数・学習率・epoch）を、実際に手元で切り替えながら確認できるデモである。

- **データ**：以下の3種類を切り替えられる。データはページを開くたびに変わらないよう、数値として固定して持たせている（実行のたびに乱数で作り直すことはしない）。
  - 4件・誤差のない一次のデータ（１．と同じ y = 2x + 1 の4組）
  - 50件・ばらつきのある一次のデータ
  - 50件・ばらつきのある二次のデータ
  - 上記2つの50件データには、大きく外れた3件を追加するチェックボックスを用意した。
- **式（モデル）**：一次・二次・三次を切り替え可能。
- **損失関数**：代表的な2つ、MSE（二乗誤差）とMAE（絶対誤差）を切り替え可能。外れ値を追加すると、この2つの挙動の違い（外れ値への引っ張られ方の違い）が確認しやすくなる。
- **初期値**：a, b, c, d（式の次数に応じて表示）を、適切な初期値（0）から変更可能。
- **学習率**：式の次数に応じた目安値を自動設定するが、変更可能。
- **epoch（回数）**：1, 10, 100 のボタンをクリックすることで、その回数分を累積して学習を実行する。
- 実行後は、誤差（Loss）と a, b, c, d の値が表示される。「リセット」で初期値の状態に戻る。

[サンプルプログラムを開く](https://tasamu61.github.io/MyAiStudyPre/2.Configuration/02-5RegressionLab.html)

## 4.発展：係数の意味、Lossの推移を詳しく見る
　上のサンプルをさらに掘り下げた、2つの発展的なデモも用意している。あわせて確認すると理解が深まる。

- [式をあてはめる ― 意味のある係数、意味のない係数](https://tasamu61.github.io/MyAiStudyPre/2.Configuration/02-1Loss_explorer.html)  
  データの次数と、あてはめる式の次数を独立に選べる。式がデータに対して余分な次数を持っていると、その係数がどう動くか、また損失関数（MSE/MAE/Huber）を変えると外れ値への反応がどう変わるかを、Lossと各係数の推移グラフで確認できる。
- [谷がひとつじゃない場合 ― 局所解と初期値](https://tasamu61.github.io/MyAiStudyPre/2.Configuration/02-x-1.html)  
  上で触れた「初期値によって結果が変わることがある」を、実際に谷が複数ある損失関数で体感するデモである。
