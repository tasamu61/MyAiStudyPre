# ２．学習プロセスの構成
　１．ではデモプログラムを提示し、実行したがそれを構成する内容について機械学習上で持つ意味、効果などについて説明する。
その詳細やシステム化における現場での応用実例については、本章での説明をもとにしてAIなどを活用し、理解を進めていただきたい。


式、モデル	y=a*x+c を使用しましたが	
	二次式：y=a*x²+b*x+c	
	三次式：y=a*x³+b*x²+c*x+d	
	や他にも多くの数式が考えられます。	
	実際のデータ、目的などによって決まるでしょう。あるいはいくつか試行すること	
	が必要かもしれません。	
	以下のようなキーワードでAIに質問し、納得いくまで問答してみてください。	
	「二次式による回帰が実際の業務で使われる例を、ITエンジニア向けに教えて」	
	「一次式では表現できず、二次式なら表現できる現実のデータの例は？」	
	「三次式による回帰を使う実務上の例は？」	
	「一次、二次、三次のモデルから、実際の機械学習ではどうやってモデルを選ぶ？」	
	「モデルを複雑にしすぎると、なぜ過学習が起きる？」	
		
損失関数	(予測値 - 正解値)**2	
	予測値と正解値がどの程度違っているかを数値で表すための関数です。	
	今回採用した二乗誤差（Squared Error） で、回帰では非常に一般的です。複数データなら、	
	その平均を取った MSE（平均二乗誤差） がよく使われます。	
	いくつかの方法がありますが、損失関数をキーワードにすれば多くの情報が得られます。	
		
初期値	a=0, b=0
